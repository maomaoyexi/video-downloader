入门与设置

6 个主题
快速开始单条下载、批量链接与任务入口

单个视频：在下载页粘贴链接，回车即可，平台会自动识别。

播放列表 / 频道：支持情况由平台和链接类型决定，不能保证所有平台的列表或频道都能下载。Rplay 请使用单个点播或直播间入口；FANBOX 按创作者、帖子等归档入口处理。

批量：在输入框里每行粘一个链接；或把链接写进工具目录的 urls.txt，用工具页的「TXT 混合批量下载」。

FANBOX 单独建任务：不要把 FANBOX 与其他平台链接混在同一个任务内；不同任务仍可并行。

下载设置：从左侧主导航进入「下载设置」。点击其他设置目录项会定位并展开对应章节；再次点击当前目录项可展开或收起，章节标题也支持整行点击。

音频与进度：在「下载设置 → 输出与画质」选择「同时输出音频」时，先完成视频下载，再从视频中提取配套音频。同一进度条会切换到音频阶段并从 0% 重新计算，不是两阶段加权后的任务总百分比。

提取失败：配套音频提取失败时，该链接按失败记录，已成功保存的视频会保留。检查 FFmpeg 和具体任务日志，不能只凭视频存在就判断音视频都已完成。

本次参数与默认参数填写位置、作用范围与提交后的保留规则

本次参数：在「下载任务」展开「本次 yt-dlp 参数」，填写后再提交普通单条、多链接或 TXT 批量任务。它不保存为全局默认值；收起按钮只隐藏输入框，不会清空内容。

默认参数：在「下载设置 → 高级与诊断 → 默认 yt-dlp 参数」中保存，普通 yt-dlp 下载会先添加默认参数，再追加本次参数。FANBOX、Withny 等专用入口按各自选项运行。

提交之后：任务成功提交或加入队列后，会清空与已提交内容相同的本次参数；提交失败时保留，方便修改重试。进入等待开播时暂时保留，提交期间新输入的不同内容不会被清除。已提交任务后续执行失败，不会自动回填参数。

填写示例：--sleep-requests 1 设置请求间隔，--retries 10 设置重试次数。参数间用空格分隔，含空格的值使用英文引号；遇到参数错误时，先记录原内容，再用单条任务验证。

Cookie 配置登录方式、凭据文件与访问权限

登录只提供账号已有权限，不能绕过付费、会员、地区或 DRM 限制。普通视频平台按需选择以下 Cookie 方式：

  1. cookies.txt 文件 — 用浏览器扩展导出，改名放到工具目录。
  2. 浏览器提取 — 在设置里选已登录且受支持的浏览器；实际可用性取决于浏览器及其登录状态。

平台差异：Fantia 必须登录，专项下载仅支持 cookies.txt 文件模式；Rplay 使用独立 Firefox 授权，普通 Cookie 文件不能替代；FANBOX 使用凭据文件或匿名访问，匿名只读取平台允许公开访问的内容。

YouTube / Twitch 等平台的年龄限制、会员内容需要相应观看权限；NicoChannel 的 Firefox JWT 方式见下方说明。

任务与并发任务队列、并行数量与 FANBOX 独立任务

「设置 → 任务与并发」默认开启任务模式，任务间默认并行 2 个，可设 1–5 个；设为 1 时任务间串行。任务内直播与视频可使用独立额度，点击任务查看具体链接、进度和日志。

FANBOX 使用独立归档任务与专项文件并发设置，请与普通视频分开提交；不同任务仍可并行。普通任务队列仅保留在本次运行中，重启后不恢复。

配置预设保存和切换常用下载配置

设置页顶部可把当前整套参数存成命名预设，一键切换。常用几组：

  • 4K 收藏 — 最高画质，留原始编码
  • 手机兼容 — 1080P + H.264 + MP4
  • 仅音频 — 只输出 MP3 320k
实用工具简明指南字幕、封面、音频处理与临时文件清理

进入「实用工具」点击对应卡片，填写链接或选择本地目录，核对选项后开始。过程与结果看下方「工具运行日志」，不要只根据进度条判断是否完成。

  • 单独下载字幕：输入链接，选择人工或自动字幕及语言，仅保存字幕；输出到对应平台的 subtitles 目录。实际可得语言取决于原内容。
  • 下载视频封面：输入一条或多条受支持的链接，仅保存 JPG；沿用当前视频输出目录与命名规则，不写入普通视频下载归档。
  • 音频格式转换：选择输入目录、目标格式等选项后转换。确认输出可用前保留源文件，涉及删除源文件的选项请谨慎选择。
  • 音频响度统一：按目标响度处理不同音频，适合统一听感；单次模式较快，双次模式先分析再处理。
  • 音频音量调整：按指定增益提高或降低音量。放大过多可能失真，先处理少量文件检查效果。
  • 清理临时文件：可能删除下载恢复数据；未确认不再需要续传前，不要随意清理 .part、.ytdl 等文件。

输出与源文件：格式转换默认在源文件旁输出，已有输出会跳过，删除源文件选项默认关闭。响度、音量工具分别默认使用源目录下的 loudnorm_output/、volume_output/，也可另设目录；它们不会覆盖已有输出。

字幕、封面工具若提示任务占用，先完成或取消活动队列。音频处理需要停止时使用「停止音频工具」，之后按完成日志检查已生成文件。

平台与录制

6 个主题
直播录制录制模式、平台差异与停止收尾

直播模式：在「设置 → 直播设置」选择全局模式，并可分别设置支持追开播的平台默认方式。开始直播任务前会检查状态：未开播可加入蹲开播；已开播会显示开播时间和已开播时长，并让你确认录制方式；追开播不可用时会提示原因并降级为从当前时刻。

Bilibili：粘贴 live.bilibili.com/房间号，默认从当前时刻录制；普通观看侧无 DVR，不支持追开播。

Twitch：粘贴频道 URL 录制当前直播；仅当本场有可访问的增长中 VOD 时才可能追开播。/videos/ 链接是回放。

TwitCasting：主播页默认从当前时刻录制；/movie/ID 下载单条，/show 拉取历史列表。密码保护内容会弹窗要求输入密码；在平台专项设置中可选择记住密码或保存到 XLSX，两项默认关闭。XLSX 以明文保存密码，除非获得明确授权，请勿发送给其他人。

Rplay：支持已接入直播源的状态检查、等待开播与录制；Twitch 转播要求源频道仍在直播且具有观看权限，Rplay 凭据不会转交给 Twitch。

录制期间需保持工具运行；停止后先收尾，再验证音视频和文件完整性。恢复失败时会保留已录制内容与报告。

直播弹幕与字幕导出

在「下载设置 → 直播设置 → 弹幕设置」开启采集，选择 SRT、ASS 或同时导出，并按需展开「各平台弹幕默认值」覆盖全局选择。能否采集取决于平台、当前账号权限与直播源。

格式与时间：SRT 用于常规字幕显示，ASS 可保留弹幕排布。时间微调以毫秒为单位，正数延后、负数提前；录制结束后可按当前格式和微调重新导出。

缺失或不同步：查看会话中的 comments-report.json，核对来源、录制起点和时间精度；不能仅凭视频录制成功认定弹幕完整。

匿名化：仅作用于本次会话的派生字幕和事件库。原始 XML、聊天 JSON 等仍可能保留昵称与账号信息，分享前需另行检查。

Bilibili 1080P登录、画质与分 P 选择

1080P 及以上需要登录 Cookie；标准 1080P 只要登录账号，不需要大会员。

关键一步：导出 Cookie 前，先在浏览器里把播放器画质手动切到 1080P 高清，Cookie 里的 CURRENT_QUALITY 才会正确。

分P 与合集会自动全部下载，也可在设置里改成「弹出选择」。

Rplay 登录与点播Firefox 登录来源、支持范围与续传差异

Rplay 点播：支持单个 HLS 点播；受限内容需在 Firefox 登录后，在「Cookie 登录」配置独立的 Rplay 登录来源与配置。暂不支持分离音画；未完成文件再次下载会重下，不能承诺断点接续。

FANBOX 预览与归档访问方式、预览筛选、下载所选与资源校验
  1. 在「下载设置 → 平台专项 → FANBOX」启用平台，选择匿名访问或凭据文件。匿名仅能访问公开内容；登录账号仍须具有对应权限。
  2. 在下载页粘贴创作者主页或单帖链接，FANBOX 与其他平台分别创建任务；不同任务仍可并行。
  3. 点击「预览」按当前全局选项抓取帖子列表；若需单独调整本次选项，可从「抓取并下载」入口打开任务选项弹窗。预览用于检查范围，不等于附件已经下载。
  4. 按标题、日期、资源类型等条件筛选，勾选帖子或资源。受限帖子的公开封面可以单独获取，但不代表正文和附件已解锁。
  5. 点击「下载所选」，查看该归档任务的具体进度与错误。本次任务选项不覆盖全局默认值。
  6. 完成后在「内容归档」详情中打开归档、导出清单或「校验资源文件」。结合具体资源与校验结果确认是否齐全。

FANBOX 归档：支持创作者主页、单帖、标签及账号可访问的赞助/关注集合。下载前可预览和选择帖子、附件，本次设置不覆盖全局默认值。

可归档正文、图片、附件、封面、原始 JSON、可选评论和外链清单；外链仅记录，不下载外站内容。粉丝卡、评论、正文和附件是否可用取决于当前账号权限与平台返回，请核对清单和具体文件结果。

恢复与重试：暂停、部分完成或失败的归档，可按当前状态使用「继续」或「重试失败文件」；校验和恢复操作是否可用，以该任务实际显示的按钮为准。

Withny 存档与录制HAR 存档、YAML 配置与文件位置

历史存档：选 Withny 平台，点「选择 HAR 并下载」，选浏览器导出的「包含内容」HAR。

直播录制：完整保留依赖包中的 dependency/Withny/ 受管组件及配套 manifest，点「选择配置并录制」并选择 YAML 配置。受管组件不可用时可能回退旧工具，应核对任务记录和评论报告。

输出与配置：程序生成当前会话的私有配置，不改写原配置；输出和部分收尾选项由本工具接管，请按任务记录与会话报告查找文件。

限制与隐私：仅处理未加密的普通 HLS 存档；检测到 DRM、加密或缺失签名会拒绝。HAR 含登录凭据，用完请删除，不要分享。

Twitter / NicoChannel链接类型与 Firefox 登录令牌

Twitter / X：推文链接直接提取视频，Space 链接下载音频。未登录访问限流较严，建议开浏览器 Cookie 模式。

NicoChannel：从 Firefox 读取未过期的 JWT 登录令牌，请先在 Firefox 里登录。浏览器令牌过期时需重新刷新登录页面。

下载记录、跳过与重新下载归档命中、同名覆盖与临时文件保留

记录不等于文件完整：历史和归档记录说明曾经处理过链接，不能证明本地文件仍存在或没有损坏；请同时检查任务统计、实际文件和适用的校验报告。

普通视频命中归档：按提示选择「重新下载」或「跳过」，默认等待 20 秒未选择会跳过并继续队列。跳过单独计数，不算新下载成功。

重新下载：只清理本次命中的普通视频归档记录，其他记录保留；按当前输出目录和命名规则覆盖相同路径的视频及配套音频，不生成编号副本。改过目录、模板或格式时，输出位置也可能改变，重要旧文件先备份。

FANBOX：通过内容归档查看资源与记录，按任务提示处理复用、冲突或单独重试。父任务完成不能代替逐项校验，也不要为了单个文件直接清空整库记录。

临时文件：.part、.ytdl 和分片是恢复数据，不是最终视频。清理前确认没有需要继续的下载；删除后可能无法复用原有进度。

                常见问题速度、登录、中断恢复与后台运行
                

            
速度慢：先检查线路、代理、平台限流和同时运行的任务，再调整并发。下载限速推荐 5–10 MB/s；高速或大批量下载可能导致 IP 或账号被限制或封禁，相关后果由使用者自行承担。

            
提示需要登录：先确认账号在浏览器里能观看，再按对应平台的 Cookie、Firefox 或凭据文件方式配置。

            
中断了：续传取决于平台、资源和下载方式。普通 yt-dlp 下载通常可复用未完成文件；TwitCasting 会校验并复用完整分片；FANBOX 按检查点及资源验证决定复用或重下；Rplay 未完成文件重试会重下。

            
关闭网页：有任务时确认关闭后，任务继续在后台运行；无任务时关闭网页，程序会在 30 秒后退出。不要关闭后端控制台，彻底退出请用左侧底部「退出工具」。

                  
网站改版下不动：普通 yt-dlp 提取失败可在工具页更新核心；Rplay 插件或 FANBOX 接口兼容问题还应检查程序与配套依赖版本，并保留相关日志。

                  
自动更新失败：更新弹窗提供「前往 GitHub 手动更新」。关闭旧程序后，按发布页说明下载新版 EXE 和配套依赖，保留设置、Cookie 与 download/；若已退出程序后替换失败，本地错误说明中也会保留链接。
