      使用帮助

      快速开始
      1. 粘贴 YouTube 或 B 站点播链接。
      2. 打开「下载选项」选择画质、仅音频或字幕，再点「开始下载」。
      3. 下载完成后，可在任务卡或「历史」播放和打开文件位置。文件保存在「下载 / 多平台下载」。
      批量下载与分集

      一行一个链接，每批最多 20 条。可以点「导入 TXT」填入链接，再检查后提交。

      单独提交 B 站多 P 或 YouTube 播放列表链接，可以先勾选分集。「队列详情」会显示每条的状态。点「跳过当前条」会继续下一条，也可以停止整个队列。

      Cookie 与网络

      遇到登录验证时，先在浏览器确认账号能播放该视频，再到「设置 → 平台 Cookie」为对应平台导入 Netscape 格式的 cookies.txt，并打开该平台的开关。「已配置」表示文件已导入。

      手机 VPN 能正常访问平台时，通常关闭手动代理。需要代理时，在「网络与代理」填写手机能访问的 HTTP 或 SOCKS5 地址和端口。下载限速和分片并发可独立设置。

      专项归档

      在「设置 → 专项归档」输入 FANBOX 公开单帖链接，先点「预览帖子」，再点「保存 ZIP」。归档保存在「下载 / 多平台下载 / FANBOX」。

      常见问题

      下载超时或息屏后停住

      超时先确认手机能访问该平台，再核对代理地址、端口或 VPN。首次下载会准备运行组件，可能需要多等一会儿。

      息屏后进度停住时，可检查系统应用详情里的电池使用和后台运行设置。

      画质、封装或字幕不可用

      画质不可用时可试「自动」或较低画质。WebM 需要平台提供兼容的音视频流，可在「输出与画质」改选 MP4 或 MKV。

      「同时下载字幕」保存平台提供的人工字幕为 SRT。缺少字幕时，已保存的视频仍可播放。

      找不到下载的文件

      在「历史」找到对应记录，点「打开文件位置」。也可以在「设置 → 工具箱」打开总下载目录。文件移动或删除后，原记录仍会保留。
