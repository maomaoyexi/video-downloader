============================================================
         Withny 历史存档 HAR 获取与下载指南
============================================================

适用内容：已购买并获得保存许可的 Withny 历史存档
支持浏览器：Chrome / Edge
使用入口：下载任务 → Withny → 选择 HAR 并下载

一、重要说明

HAR 是浏览器导出的网络请求记录，不是视频文件。它可能包含 Cookie、登录会话和临时签名地址，请勿分享、上传网盘或提交到代码仓库，下载完成后建议立即删除。

本功能仅处理你已经购买并获得保存许可的普通未加密 HLS 历史存档。检测到 DRM、加密 HLS、缺失媒体播放列表正文或签名 Cookie 时，程序会拒绝下载。

二、开始前准备

1. 使用 Chrome 或 Edge 登录 https://www.withny.fun/
2. 确认目标历史存档已经购买且能够正常播放
3. 确认工具目录存在 ffmpeg.exe
4. 打开目标存档详情页：https://www.withny.fun/user/archives/存档ID

三、导出包含内容的 HAR

1. 按 F12 或 Ctrl + Shift + I 打开开发者工具
2. 进入「网络」或 Network 标签
3. 勾选「保留日志」或 Preserve log
4. 清空旧网络记录后按 Ctrl + R 刷新页面
5. 等待播放器出现并播放 5～10 秒
6. 确认请求列表出现 m3u8 和 ts 请求
7. 按 F1 打开开发者工具设置
8. 在 Network 设置中启用 Allow to generate HAR with sensitive data
9. 回到网络请求列表，右键选择「将所有内容保存为 HAR（包含敏感数据）」
10. 导出后尽快开始下载

必须导出包含内容和敏感数据的 HAR。archive.withny.fun 使用 CloudFront 签名 Cookie，普通脱敏 HAR 会缺失必要 Cookie；HAR 还必须包含媒体清单正文，以便程序验证是否加密。

四、在工具中下载

1. 启动视频下载工具
2. 进入「下载任务」页面
3. 在平台栏选择 Withny
4. 点击「选择 HAR 并下载」
5. 选择刚导出的 HAR
6. 选择视频保存位置和文件名
7. 建议使用 MP4，也支持 MKV 和 TS
8. 验证通过后会自动开始下载
9. 可通过现有进度、日志、历史和停止按钮管理任务

五、常见错误

「HAR 中没有有效的 Withny 历史存档页面」：请从正确的已购买存档详情页重新刷新、播放并导出。

「HAR 中没有检测到 HLS 播放列表」：请等待播放器成功加载，确认 Network 中出现 m3u8 后再导出。

「未取得媒体播放列表正文」：请使用包含内容的 HAR 导出方式。

「检测到加密 HLS」或「检测到 DRM」：该内容不符合本工具的安全处理范围，无法继续。

「缺少依赖：ffmpeg.exe」：将可信来源的 ffmpeg.exe 放到主程序同一目录。

HTTP 403 或签名过期：重新启用 Allow to generate HAR with sensitive data，刷新并播放后重新导出，随后立即下载。

HAR 超过 64 MB：清空网络记录，刷新后只播放 5～10 秒并立即导出。

六、安全检查清单

□ 已获得目标内容的保存许可
□ 已打开正确的已购买存档详情页
□ 已在 Network 中清空旧请求并刷新页面
□ 播放器成功播放 5～10 秒
□ 已看到 m3u8 和 ts 请求
□ 已启用 Allow to generate HAR with sensitive data
□ HAR 包含响应内容且不超过 64 MB
□ ffmpeg.exe 与主程序位于同一目录
□ 下载完成后删除 HAR 并清空回收站

七、Withny 直播监控与录制

外部工具：withny-dl-windows-amd64.exe v2.0.0

1. 从 https://github.com/Darkness4/withny-dl 获取可信版本的 withny-dl，并放到视频下载工具主程序同一目录。
2. 按 withny-dl 官方文档准备 config.yaml、credentials.yaml 等文件。凭据文件和缓存令牌必须保存在本机，不要上传或分享。
3. 在下载任务页选择 Withny，点击“选择配置并录制”。
4. 选择 yaml 或 yml 配置文件。配置中的相对路径会以该配置文件所在目录为基准。
5. withny-dl 会持续监控配置中的多个频道，有直播时自动录制；界面显示 LIVE 状态，日志页显示经过敏感字段过滤的工具输出。
6. 点击“停止”会结束监控及当前录制进程。录制结束后的拼接、清理和封装行为由 withny-dl 配置决定。

注意：withny-dl 的配置、登录凭据和缓存令牌不由本工具生成。首次使用前请先阅读其官方配置示例，并确保只录制你有权保存的内容。
